For administrators

nginx can't reach the console (PHP) or webmail yet. On the server, check the web logs:

cd /opt/rabbittech-mailserver/app
docker compose ps
docker compose logs --tail=200 php-fpm-mailcow nginx-mailcow

If the logs show "access denied" for the database, the passwords in .env don't match the database volume. Test them with:

source .env; docker compose exec mysql-mailcow mysql -u${DBUSER} -p${DBPASS} ${DBNAME}

TZ in .env must be a time zone name such as Asia/Kathmandu, without spaces.
